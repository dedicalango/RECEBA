# RECEBA

Este repositório é o bootstrap do RECEBA.

1. Crie um repositório chamado `RECEBACompiled` e envie a pasta `RECEBACompiled` do pacote.
2. Crie outro repositório chamado `RECEBA` e envie `NewMainScript.lua` deste diretório.
3. Em `NewMainScript.lua`, troque `SEU_USUARIO_GITHUB` pelo seu usuário do GitHub.
4. No Xeno, use a linha de `XENO.txt` também trocando o usuário.

O bootstrap cria `receba/`, salva a revisão do repositório e chama `main.lua`.
